    Quickstart

    Two packages ship the same engine. Pick one; only the command name differs.

    1. Install the runtime

      Python 3.8+. The install compiles the engine: CPU by default, Metal on macOS. This model wants a GPU, so pick a backend.

      GGK_CUDA=1 pip install ggk      # NVIDIA
GGK_HIP=1 pip install ggk       # AMD ROCm
GGK_VULKAN=1 pip install ggk    # Vulkan
pip install ggk                 # CPU only: works, but allow most of an hour per model

      The 3D server is in ggk 1.1.4 and newer, and in gguf-core releases after 1.0.2. On Windows cmd, set the variable first: set GGK_CUDA=1, then pip install ggk.

    2. Get the model file

      One GGUF holds the whole pipeline. Download it from huggingface.co/gguf-org/trellis2-4b-gguf.

      FileWhat it isSize
      trellis2-4b-nvfp4.ggufTRELLIS.2-4B, NVFP4 weights. The one used on this page.5.65 GB

    3. Start the server

      --serve answers over HTTP instead of writing one file and exiting.

      ggk -m trellis2-4b-nvfp4.gguf --serve --port 8888

      It listens on 127.0.0.1:8888 at once. Add --api-key <key> to require a key, --host 0.0.0.0 to serve your network, --mesh-pipeline 1024_cascade for the full-resolution pipeline (wants about 11 GB, or patience).

    4. Turn a picture into a model

      curl -f http://127.0.0.1:8888/v1/images/edits \
  -F image=@sheep.png \
  --output sheep.glb

      The answer is the mesh file itself, when it is done: about 80 seconds on a 6 GB laptop GPU. Or skip the server and write one file: ggk -m trellis2-4b-nvfp4.gguf --ref-image sheep.png -o sheep.glb

      Keep the -f. Without it a failed request saves the JSON error message as sheep.glb.

    API

    OpenAI has no 3D endpoint, so the server borrows the one with the same shape: the image edit. An image goes in, an asset comes out. OpenAI SDKs work with base_url set to your server.

    POST /v1/images/edits

    A multipart form with the picture as a file part, or a JSON body with the picture as base64. The response is the mesh file itself.

    FieldMeaning
    image requiredThe picture: PNG, JPEG, WebP or BMP. A file part in a form; base64 or a data: URI in JSON. URLs are not fetched.
    maskThe subject mask, white where the object is, the size of the image. Optional: an alpha channel does the same, and a plain backdrop is removed automatically.
    pipeline512, 1024, 1024_cascade, 1536_cascade or auto (default: by GPU memory).
    output_formatglb (default), ply or obj.
    response_formatLeave it out for the file. b64_json wraps it in OpenAI's images object: data[0].b64_json.
    seedDefault 42: the same picture returns the same mesh. -1 for a new take.
    steps, guidanceSampling steps per stage (12) and guidance strength (7.5).
    backgroundauto (default) or keep: use the picture as it is, backdrop included.
    texturefalse skips the material stages: the bare shape, in about two thirds of the time.
    model, prompt, sizeAccepted and ignored. n must be 1.

    The mesh

    .glbBinary glTF 2.0, y-up, inside the unit cube. POSITION, NORMAL, COLOR_0 (base colour) and per-vertex metallic and roughness in _METALLIC_ROUGHNESS.
    .ply, .objz-up, with vertex colours. PLY also carries metallic and roughness per vertex.
    SizeDense: about 0.8 M vertices and 1.6 M triangles at 512³, 45 to 60 MB as GLB. Colour is per vertex, there are no UVs or texture maps. Decimate and bake in Blender before shipping it in a game.
    HeadersX-Mesh-Vertices, X-Mesh-Triangles, X-Mesh-Resolution, X-Seed.

    Other endpoints

    GET /health{"status":"ok"} as soon as the port is open.
    GET /v1/modelsThe model, with meta.type = "image-to-3d", its pipelines and output formats.
     
    curl -f http://127.0.0.1:8888/v1/images/edits \
  -F image=@sheep.png \
  -F pipeline=512 \
  -F seed=7 \
  --output sheep.glb

# the bare shape as PLY, with an API key
curl -f http://127.0.0.1:8888/v1/images/edits \
  -H "Authorization: Bearer $API_KEY" \
  -F image=@sheep.png \
  -F texture=false -F output_format=ply \
  --output sheep.ply
    # request.json: {"image": "<base64 of the file>", "seed": 7}
python -c "import base64, json; json.dump({'image': base64.b64encode(open('sheep.png','rb').read()).decode(), 'seed': 7}, open('request.json','w'))"

curl -f http://127.0.0.1:8888/v1/images/edits \
  -H "Content-Type: application/json" \
  -d @request.json \
  --output sheep.glb
    import base64, json, urllib.request

image = base64.b64encode(open("sheep.png", "rb").read()).decode()
req = urllib.request.Request(
    "http://127.0.0.1:8888/v1/images/edits",
    data=json.dumps({"image": image, "seed": 7}).encode(),
    headers={"Content-Type": "application/json"},
)
# the answer comes when the mesh is done: allow minutes
with urllib.request.urlopen(req, timeout=1800) as res, open("sheep.glb", "wb") as f:
    f.write(res.read())
    import base64
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8888/v1",
                api_key="not-needed", timeout=1800)

result = client.images.edit(
    model="trellis2",
    image=open("sheep.png", "rb"),
    prompt="",
    response_format="b64_json",
)
with open("sheep.glb", "wb") as f:
    f.write(base64.b64decode(result.data[0].b64_json))

    Errors come back as JSON: {"error": {"code": 400, "message": "…"}}. One model is generated at a time; concurrent requests queue.
